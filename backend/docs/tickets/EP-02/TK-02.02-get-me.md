## O que entregar

Depois de escolher um usuário, o frontend chama `GET /me` e sabe quem entrou, quais telas mostrar e o que o leitor de tela deve anunciar ("Você entrou como Marina, massoterapeuta.").

- `GET /me`, identificado, sem `@Roles`: qualquer papel responde 200.
- Corpo: `id`, `role`, `effectiveRoles` (da função de herança do TK-02.01; `ADMIN` → `["ADMIN", "HR"]`), `name`, `firstName`, `therapistId` (do perfil de massoterapeuta, `null` nos demais casos) e `spokenText`. Sem e-mail.
- `firstName`: primeira palavra do nome, sem espaços nas pontas, por uma função pura compartilhada.
- `spokenText` e o papel por extenso vêm do catálogo de mensagens: "Você entrou como {primeiro nome}, {papel por extenso}."
- Dados lidos pelo próprio módulo `auth/` (usuário + perfil de massoterapeuta).
- Remover a rota legada `GET /booking/me` e o método que a atende; os testes que a usam como "rota identificada qualquer" passam a usar `GET /me`.
- Acrescentar a linha `GET /me` ao teste da matriz de permissões.

Fora deste ticket: e-mail no perfil, foto, unidade do usuário, tela do frontend (TK-09.02).

## Critérios de aceite

- [x] **Dado** um massoterapeuta com perfil, **quando** chama `GET /me`, **então** recebe `role` `THERAPIST`, `effectiveRoles` `["THERAPIST"]`, `firstName`, `therapistId` preenchido e `spokenText` "Você entrou como {primeiro nome}, massoterapeuta."
- [x] **Dado** um `ADMIN`, **quando** chama `GET /me`, **então** `effectiveRoles` contém `ADMIN` e `HR`, e `therapistId` é `null`.
- [x] **Dado** um colaborador com nome "Beatriz Lima", **quando** chama `GET /me`, **então** `firstName` é "Beatriz" e o corpo não tem e-mail.
- [x] **Dado** um usuário com nome " Ana  Souza ", **quando** o primeiro nome é derivado, **então** é "Ana".
- [x] **Dado** um usuário com nome de uma palavra só, **quando** o primeiro nome é derivado, **então** é o próprio nome.
- [x] **Dado** qualquer um dos quatro papéis, **quando** chama `GET /me` identificado, **então** recebe 200; sem identificação, 401 com a mensagem do catálogo.
- [x] **Dado** a rota legada `GET /booking/me`, **quando** é chamada, **então** responde 404.
- [x] O `spokenText` tem teste de formato: começa por "Você entrou como", traz só o primeiro nome, uma frase.
- [x] `npm run test`, `npm run test:e2e`, `npm run lint` e `npm run build` passam.
