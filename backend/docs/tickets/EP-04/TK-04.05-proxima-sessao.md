# TK-04.05 — Próxima sessão para o card de lembrete

Status: ✅

## Contexto

Disponibilizar a próxima sessão confirmada do colaborador para o card exibido ao entrar na página inicial. O protótipo não envia e-mail; a informação vem da API.

Referências:

- [Spec do EP-04](../../specs/EP-04-agendamento-do-colaborador.md#tk-0405--próxima-sessão)
- [Requisito RF-09](../../requisitos.md)
- [Roadmap do projeto](../../roadmap.md), linha `TK-04.05`

## Critérios de aceite

- **Dado** que o colaborador possui uma sessão futura confirmada;
- **Quando** consulta a próxima sessão;
- **Então** recebe os dados do card e um `spokenText` curto com data, hora, terapeuta e sala.

## Testes esperados

- Unitários para selecionar a primeira sessão futura elegível.
- E2E para resposta com sessão e resposta sem sessão (`appointment: null`).
- E2E para privacidade, primeiro nome, ordem e fuso `America/Sao_Paulo`.
